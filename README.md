# Employee Management (Next.js + Drizzle)

Simple employee management demo built with Next.js, TypeScript, and Drizzle-style DB access. The project includes a JSON-based development fallback so API routes work locally without PostgreSQL.

**Quick Start**

- **Requirements:** Node 18+, npm.
- Install dependencies:

```powershell
cd C:\Users\user\OneDrive\Desktop\employee
npm ci
```

- Start dev server (dev fallback used if `DATABASE_URL` is not set):

```powershell
npm run dev
```

**Database / Dev fallback**

- The app prefers a Postgres `DATABASE_URL`. If not provided, the code uses a JSON dev store so the API endpoints remain usable during development. See `src/db/devStore.ts` for implementation details.

To run with Postgres (recommended for full features):

1. Start Postgres (Docker):

```powershell
docker run --name employee-postgres -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres:15
```
2. Set `DATABASE_URL` in your environment (PowerShell example):

```powershell
$env:DATABASE_URL = "postgres://postgres:postgres@localhost:5432/postgres"
npm run dev
```

**Importing CSV data**

The repository contains `scripts/importData.js` to import CSVs into Postgres (or provide a JSON fallback). Example usage:

```powershell
node scripts/importData.js --source ./data/employees.csv
```
